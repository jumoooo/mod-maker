# 만들기 전에 그림부터

**화면이 있는 mod(창·띠·상태줄·토스트)는 만들기 전에, 어떻게 보일지 그린 HTML 을 사람에게 보이고 승인받은 뒤에 만든다.**
사람은 그림을 몇 초 만에 읽고, 본 것만 승인할 수 있다. 다 만든 뒤의 화면은 이미 정해 버린 것을 보여 줄 뿐이다.

## 그림은 이렇게 만든다

1. **버전마다 HTML 파일 하나.** 작업 폴더 아래 `mod-previews/<mod 이름>_v<N>.html`. 앞 버전을 덮어쓰지 않는다 — 고쳐 달라고 하면 `v<N+1>` 을 새로 쓴다.
   작업 폴더가 마땅치 않으면 사용자 홈의 `mod-previews/` 에 둔다.
2. **바탕은 이 폴더의 `templates/preview.html`.** 복사해서 `PREVIEW` 객체만 채운다 — 제목, 테마 색, 그릴 화면들. 틀이 어두운 화면과 밝은 화면 두 벌로 그려 준다.
3. **테마 색은 지금 저장된 것으로.** `templates/ui/theme.ts` 의 `dark` · `light` 값을 읽어 `PREVIEW.theme` 에 그대로 넣는다. 색을 새로 짓지 않는다.
4. **실제 자료로 그린다.** 그 mod 가 보여 줄 진짜 내용(오늘의 할 일, 실제 파일 이름, 실제 문구)으로. 채움 글이나 지어낸 행을 쓰지 않는다. 자료를 모르면 먼저 묻는다.
5. **고치는 것이면 지금 화면과 바꾼 화면을 나란히.** 새로 만드는 것이면 바꾼 화면만, 폭이 넓을 때와 좁을 때.
6. **상태 낱말·기호는 `templates/ui/tokens.ts` 의 것만.** 「당신 차례」「진행 중」「끝남」과 그 기호를 그대로 쓴다.

## 보이기 전에

- **Playwright 가 있으면**(이 세션에 `mcp__playwright__*` 도구가 보이면) 그 HTML 을 직접 열어 찍고, 찍은 그림을 읽어 줄이 어긋나거나 넘치는 곳을 고친다.
  `file://` 주소가 막혀 있으면 그 폴더에서 잠깐 파일 서버를 띄워 `http://127.0.0.1:<포트>/` 로 연다. 다 보면 서버를 내린다.
- **없으면** 그 단계를 건너뛴다. 멈추지 않는다. 보일 때 「Playwright 가 없어 제가 미리 찍어 보지 못했습니다. 어긋난 곳이 보이면 말씀해 주세요」 한 줄을 붙인다.

## 보인다

기본 브라우저로 띄운다. 경로는 따옴표로 감싼다.

| 기계 | 명령 |
|---|---|
| Windows (PowerShell) | `Start-Process "<파일 경로>"` |
| Mac | `open "<파일 경로>"` |
| Linux | `xdg-open "<파일 경로>"` |
| WSL | `wslview "<파일 경로>"` 가 있으면 그것, 없으면 `explorer.exe "$(wslpath -w "<파일 경로>")"` |

띄우는 명령이 없거나 실패하면 파일의 전체 경로를 알려 주고 직접 열어 달라고 한다. 그것도 그림을 보인 것이다.

그리고 **질문 하나** — 「이 모양으로 만들까요?」 — 와 함께 그림 파일의 전체 경로, 그림의 각 부분이 무엇을 하는지 짧은 목록을 붙인다.

## 승인 뒤에만 만든다

- 사람이 그 버전에 「좋아」「이대로」라고 한 뒤에 코드를 쓴다. 그 전에는 쓰지 않는다. 절반만 만들고 보이지 않는다.
- **승인된 버전이 만들 것의 기준이다.** 만들다가 그림과 달라질 수밖에 없으면(엔진의 제약, 없는 값) 끝난 뒤 보고에 무엇이 왜 달라졌는지 적는다.
- 고쳐 달라는 말이 오면 다음 버전 파일을 쓰고 같은 질문을 다시 한다. 앞 버전을 두고 다투지 않는다.
- 다 만들면 **실제 화면**도 보인다. Playwright 로는 터미널 화면을 찍을 수 없으니, 켜는 법을 알려 주고 승인된 그림과 견주어 달라고 한다.

## 건너뛰는 때

| 경우 | 하는 일 |
|---|---|
| 사람이 「그림 없이 바로 만들어」「확인 없이」라고 했다 | 바로 만든다. 끝난 뒤 결과 화면을 켜는 법과 함께 알린다 |
| 화면이 없는 mod(도구 호출 막기, 기록만 하기) | 그릴 것이 없다. 계획 한 블록만 보인다 |
| 문구 한 줄, 색 하나만 바꾼다 | 그래도 그림 한 장. 「서두른다」는 건너뛸 까닭이 아니다 |

## 하기 쉬운 잘못

- 「다 만들고 화면을 보여 드리겠다」 — 그것은 보고이지 미리 보기가 아니다.
- 「글로 설명하면 된다」 — 글은 그림이 아니다.
- 「디자인은 이미 정해져 있다」 — 사람은 아직 못 봤다.
